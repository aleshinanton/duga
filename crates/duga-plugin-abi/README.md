# duga-plugin-abi

## Description

WIT contract and shared plugin ABI types for `duga`. This crate defines the host/guest plugin boundary, plugin metadata structures, WASI capability configuration, and schema-compatible shared types.

## Dependencies

- **Internal:** none
- **Runtime:** `serde`, `serde_json`, `schemars`
- **Features:** `host`, `guest`
