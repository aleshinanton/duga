# duga-types

## Description

Core wire and on-the-loop datatypes for `duga`. This crate contains shared message, tool-call, tool-result, schema, LLM, configuration, and error structures used across the workspace.

## Dependencies

- **Internal:** none
- **Runtime:** `schemars`, `serde`, `serde_json`, `thiserror`, `time`, `uuid`
- **Development:** none
